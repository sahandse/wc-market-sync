# همگام‌سازی بازار ووکامرس

افزونه همگام‌سازی محصولات ووکامرس با باسلام و ترب.

## ویژگی‌ها
- همگام‌سازی ایجاد، ویرایش و حذف محصول
- همگام‌سازی موجودی
- همگام‌سازی قیمت
- درصد افزایش قیمت جداگانه برای باسلام و ترب
- پشتیبانی از محصولات متغیر، رنگ و سایز
- نگاشت دسته‌بندی
- آماده‌سازی برای آپلود تصویر به باسلام
- همگام‌سازی سفارش‌های باسلام با ووکامرس
- رابط فارسی و مینیمال
