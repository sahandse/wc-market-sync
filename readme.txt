== Description ==
WC Market Sync provides a Persian-first synchronization foundation for WooCommerce products, stock, price and marketplace orders.

== Installation ==
1. Upload the wc-market-sync folder to /wp-content/plugins/
2. Activate the plugin.
3. Open WooCommerce > همگام‌سازی بازار.
